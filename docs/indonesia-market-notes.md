## 1. 节庆日历

### 1.1 年度节庆主轴

印尼零售的年度节律由伊斯兰历（Hijri）驱动，而非公历。斋月（Ramadan）与开斋节（Lebaran/Idulfitri）构成无可争议的销售峰值。

| 节日 | 类型 | 影响窗口 | 影响权重 | 核心品类 |
|---|---|---|---|---|
| **斋月 / 开斋节** | 宗教 | 6 周 | 🔴 极高 | 食品、礼品装、穆斯林服饰、小家电 |
| **Harbolnas（12.12）** | 商业 | 2 周 | 🟠 高 | 电子产品、时尚、美妆 |
| **开斋节后返校季** | 文化 | 4 周 | 🟠 高 | 文具、校服、电子设备 |
| **独立日（8.17）** | 国家 | 1 周 | 🟡 中 | 国旗、 patriotic 商品 |
| **年末假期** | 文化 | 3 周 | 🟠 高 | 礼品、旅游用品、食品 |

**2026 年关键日期**：斋月自 2 月 19 日开始，开斋节约在 3 月 20 日前后。由于中国春节与斋月时间重叠，进口供应链面临国内断档与东南亚本地流通效率下降的双重压力[reference:0]。

### 1.2 斋月消费数据

- 印尼贸易部数据显示，2025 年斋月期间小家电线上销售额同比飙升 **180%**，美妆个护 GMV 增长 **82%**[reference:1]。
- FMCG 交易量在斋月期间可增长 **2–3 倍**，尤其是开斋节前两周[reference:2]。
- 印尼央行零售销售调查显示，2025 年 3 月（斋月期间）真实销售指数环比增长 **13.6%**，食品、饮料和烟草品类增长 **15.1%**[reference:3]。

### 1.3 节庆日历实现

`indonesia_holidays` 表存储节日数据，`ramadan_relative_day` 字段用于计算斋月相对偏移：

```python
from nrt.calendar import IndonesiaCalendar

cal = IndonesiaCalendar(year=2026)
ramadan_start = cal.get_ramadan_start()  # 2026-02-19
lebaran_date = cal.get_lebaran_date()    # 2026-03-20

# 获取斋月前 8 周到开斋节后 2 周的所有日期
window = cal.get_ramadan_window(pre_weeks=8, post_weeks=2)
```

## 2. 跨岛物流方差

### 2.1 核心原则

印尼零售供应链的核心约束不是距离，而是**提前期的方差**。从 Java 到 Papua，跨岛货运、港口拥堵和地址质量问题使交货时间高度不确定[reference:4]。

> **Measure lead time variance, not average lead time.**
> —— RetailNews Asia, Indonesia Supply Chain Guide[reference:5]

### 2.2 岛屿区域参数

| 区域 | `k_factor` | 平均提前期 (天) | 标准差 (天) | 冷链可用 | 说明 |
|---|---|---|---|---|---|
| **Java** | 0.5 | 3–5 | 1.0 | ✅ 集中 | 供应链密集，方差小 |
| **Sumatra** | 1.0 | 5–7 | 1.5 | ⚠️ 部分 | 陆路 5–6 天[reference:6] |
| **Kalimantan** | 1.0 | 7–10 | 2.0 | ⚠️ 部分 | 陆路 7–10 天[reference:7] |
| **Sulawesi** | 1.5 | 10–14 | 3.0 | ❌ 碎片化 | 需提前 30 天备货[reference:8] |
| **Papua** | 1.5 | 14–21 | 4.0 | ❌ 碎片化 | 需提前 30 天备货[reference:9] |

### 2.3 有效提前期公式

补货引擎使用以下公式计算有效提前期：

```text
LT_eff = LT_mean + k × σ_LT
```

其中 `k` 由 `island_region` 决定：

| 区域 | k | 含义 |
|---|---|---|
| Java | 0.5 | 低不确定性，适度冗余即可 |
| Sumatra / Kalimantan | 1.0 | 中等不确定性，标准冗余 |
| Sulawesi / Papua | 1.5 | 高不确定性，需要显著冗余缓冲 |

### 2.4 斋月前置补货窗口

由于斋月期间物流量激增 **30%** 且海路面临集装箱短缺[reference:10][reference:11]，前置补货窗口必须提前：

| 区域 | 首轮补货 | 次轮补货 | 原因 |
|---|---|---|---|
| Java | H-6 周 | H-2 周 | 供应链密集，窗口可稍短 |
| Sumatra / Kalimantan | H-8 周 | H-2 周 | 陆路运输需缓冲 |
| Sulawesi / Papua | H-10 周 | H-3 周 | 需提前 30 天启运[reference:12] |

## 3. Mudik 返乡效应

### 3.1 现象描述

开斋节前，大量城市人口返乡（mudik），导致：

- **城市门店**：开斋节前 1 周需求骤降（人口流出）
- **外岛门店**：开斋节后 1–2 周需求骤升（返乡人口消费）

### 3.2 建模方式

每个 `StoreProfile` 携带 `mudik_offset` 参数：

| 区域 | mudik_offset | 含义 |
|---|---|---|
| Java（雅加达等大城市） | -7 天 | 节前需求提前下降 |
| Sumatra | +7 天 | 节后需求延迟上升 |
| Kalimantan | +5 天 | 节后需求延迟上升 |
| Sulawesi / Papua | +3 天 | 节后需求延迟上升 |

预测引擎在斋月窗口内自动应用 `mudik_offset`，使城市与外岛门店的需求曲线产生差异化偏移。

## 4. 消费者行为特征

### 4.1 促销响应

印尼消费者高度促销驱动。研究表明，**折扣和捆绑都能正向影响购买决策**，但捆绑在品类关联性强的场景下效果更显著。Circle K 的案例表明，**价格促销和捆绑是最有效的促销元素**。

**系统响应**：

- 临期生鲜 → 捆绑促销（如“肉类 + 蔬菜”组合），而非单纯降价
- 斋月前 → 礼品装阶梯折扣（10–15% → 25–30%）
- Mudik 品类 → “返乡套装”捆绑

### 4.2 生鲜偏好

印尼消费者对新鲜产品的需求极为突出。**70% 的消费者在饮食中优先选择新鲜农产品**，肉类和家禽贡献了新鲜食品利润池的 24%，鱼和海鲜贡献 15%。Alfamidi 已将约 **25% 的销售面积**分配给新鲜食品。

**系统响应**：

- 三档门店的生鲜面积占比设定为 15–20%（500㎡）、25–30%（2,000㎡）、30–35%（5,000㎡）
- 生鲜 SKU 的补货频率强制为每周 ≥ 3 次（2,000㎡）或每日（5,000㎡）
- FEFO 逻辑驱动批次分配

### 4.3 品类需求分布

基于印尼零售 ABC 分析研究：

- **A 类 SKU**（约 20–30%）贡献约 **80%** 的销售额[reference:13]
- 典型 A 类品类：围巾（Scarf）贡献 69.9%，Gamis 贡献 6.7%，男装与 Umroh 服饰贡献 5.4%[reference:14]
- 便利店的加工食品占比高达 **85%**，其中零食 33%、饮料 27%、糖果 21%[reference:15]

**系统响应**：

- `abc_class` 字段驱动补货优先级：A 类 SKU 安全库存系数 × 1.5
- 斋月期间，A 类节庆品类（食品、服饰）前置补货窗口额外提前 2 周

## 5. 合规与认证

### 5.1 清真认证

清真认证（Halal）是印尼市场的准入性字段。根据 2014 年 UU No.33 规定，所有入境印尼流通和交易的产品必须通过清真认证，实施分两阶段推进[reference:16]。2025 年下半年起，Transmart、Lotte Mart、Hypermart、Indomaret、Alfamart 等主要现代贸易渠道已将清真认证列为新食品入场的必备条件[reference:17]。

**系统响应**：

- `halal_certified` 字段参与预测与促销逻辑
- 滞销清真 SKU 优先与高周转品类跨品类捆绑，利用信任传递效应
- 合规注册表按 SKU 维护证书到期日，到期前 90 天触发提醒

### 5.2 标签与注册

- **Bahasa Indonesia 标签**为强制要求[reference:18]
- **BPOM 注册**适用于食品、化妆品和补充剂[reference:19]
- 注册时间线决定上市日期，建议在第 1 个月即启动[reference:20]

### 5.3 QRIS 支付

QRIS 支付渗透率影响促销执行效率。`qris_enabled` 为 true 的门店在预测促销响应时赋予更高的弹性系数（×1.2）。

## 6. 区域市场特征

### 6.1 渠道结构

| 渠道 | 占比 | 说明 |
|---|---|---|
| 传统贸易 / Warung | 43% | 仍为主流，但现代贸易持续增长 |
| 现代贸易 / 商场 | 33% | 大卖场、标超、便利店 |
| 电商 | 19% | 增长最快，Harbolnas 期间峰值 |
| 其他 | 5% | |

### 6.2 主要城市

雅加达、泗水、万隆、棉兰、望加锡为现代零售核心城市。大雅加达地区贡献 **42%** 的零售额[reference:21]。

### 6.3 三档门店的区域适配

| 门店规模 | 最佳适配区域 | 原因 |
|---|---|---|
| 500㎡ Minimarket | Java 城市、Sumatra 主要城市 | 高密度住宅区、办公区 |
| 2,000㎡ Supermarket | Java 二线城市、Sumatra/Kalimantan 首府 | 购物中心、商圈 |
| 5,000㎡ Hypermarket | Java 郊区、主要城市外围 | 大型枢纽、郊区仓储 |
