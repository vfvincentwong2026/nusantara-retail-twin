# Assets Guide

本目录存放 README 与文档站使用的静态图像与 GIF。

## 文件规范

| 类型 | 尺寸 | 格式 | 体积上限 |
|---|---|---|---|
| 主演示 GIF | 880 × 480 | GIF / WebP | 5 MB |
| 功能截图 | 1440 × 900 | PNG | 800 KB |
| 动图 | 880 × 480 | GIF / WebP | 3 MB |
| 封面图 | 880 × 480 | PNG / JPG | 300 KB |

## 命名规范

- 序号前缀：`01-`、`02-`，保持文档引用顺序。
- 全小写，连字符分隔，不使用中文文件名。
- 动图统一以 `.gif` 结尾，静态图以 `.png` 结尾。

## 制作工具建议

- 录屏：Screen Studio（macOS）、LICEcap、OBS
- 压缩：gifski、ezgif、ImageOptim
- 截图：CleanShot X、Shottr

## 贡献方式

新增截图时请同步更新本 README 的清单，并在对应 PR 描述中说明截图来源门店规模（500 / 2000 / 5000㎡）。
