# 01 · 试点门店评估问卷

> 用途：签约前摸底，由 NRT 实施顾问与店长面对面填写，约 45 分钟。
> 填写结果将转换为本仓库的门店种子 JSON（`nrt validate` 必须全绿）。

## A. 门店基本信息

1. 店名 / 城市 / 岛屿区域（爪哇 / 苏门答腊 / 加里曼丹 / 苏拉威西 / 巴布亚）
2. 面积（㎡）：≈500 / ≈2000 / ≈5000（决定 SKU 规模档位）
3. 业态：迷你市场 / 超市 / 大卖场 / 社区店
4. 开业年份、最近一次翻新时间
5. 日均客流、客单价（IDR，可估算）

## B. 商品结构

6. 在售 SKU 总数；其中生鲜占比（%）
7. 是否有自有品牌？占比？
8. 清真（Halal）认证商品占比（%）
9. 本地采购占比（%）
10. Top 50 畅销 SKU 清单能否从 POS 导出？（能/否）

## C. 货架与空间

11. 货架组数、每组层数（单面/双面）
12. 是否有冷链柜、冷冻柜？各几台？
13. 促销端架数量；堆头区域位置
14. 现有平面图纸（CAD/手绘）能否提供？
15. 面位（Facing）目前是否有人维护清单？（有纸质/有电子/无）

## D. 补货与供应链

16. 主要供应商数量；配送频率（每日/每周几次）
17. 最小起订量（MOQ）与整箱规约约束
18. 当前安全库存策略（固定值/经验/系统）
19. 过去 3 个月缺货最严重的 10 个 SKU
20. 生鲜日均损耗率（%），主要损耗品类

## E. 节庆与本地事件

21. 门店周边 1km：清真寺数量 / 学校 / 工业区 / 旅游景点
22. 客流受 mudik（返乡）影响程度（高/中/低）
23. 斋月期间是否调整营业时间？历史销售峰值数据能否提供？

## F. 人员与数字化

24. 店长任职年限；店员人数；是否有人会用 Excel
25. 当前 POS 系统名称；能否导出 CSV/Excel 销售数据
26. 是否有 WhatsApp 群用于供应商沟通（备用通知渠道）
27. 店内网络条件（4G 路由器/宽带/无）

---

**填写后**：实施顾问将问卷答案整理为 `store_profile` 字段 + 供应商约束表，与 POS 导出一起生成真实种子，跑 `nrt validate` 校验后方可进入第 2 周。
