# Phase 8 · 印尼试点计划

目标：在 1~3 家真实印尼门店跑通「真实数据 → nrt 引擎 → 人工执行 → 复盘」闭环，
验证预测/补货/空间优化建议对缺货率与损耗率的实际改善。

## 试点节奏（8 周）

| 周 | 动作 | 产出 |
|---|---|---|
| 1 | 签署试点协议，发放评估问卷（见 01） | 门店画像 JSON |
| 2 | 数据接入：POS 导出 + 货架盘点 → 种子 JSON | 真实种子通过 `nrt validate` |
| 3~4 | 影子运行：引擎建议 vs 店长决策并行，不执行 | 建议采纳率基线 |
| 5~6 | 半执行：补货建议与空间调整建议人工执行 | 缺货率/损耗率周报 |
| 7~8 | 全执行 + 复盘 | 试点报告，决定区域扩展 |

## 成功标准（先行指标）

- 缺货率（A 类 SKU）：下降 ≥ 20%
- 生鲜损耗率：下降 ≥ 15%
- 补货建议周采纳率：≥ 70%
- `nrt validate` 每周全绿
